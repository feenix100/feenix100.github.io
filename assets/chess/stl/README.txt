Bundled Staunton-inspired STL chess set.

Expected filenames used by app.js:
  pawn.stl
  knight.stl
  bishop.stl
  rook.stl
  queen.stl
  king.stl

You may replace any file with your own STL using the same filename.
The loader automatically centers the model, places its base on the board, and rescales it to fit a square.
If a model is missing or invalid, the app falls back to built-in procedural geometry.
